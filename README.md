# Q04TI Portfolio

A responsive, single-page developer portfolio built with plain HTML, CSS, and JavaScript.

## Deploying on Vercel

Import this repository into Vercel and deploy it as-is. The root `vercel.json` selects `dist` as the production output directory, so no framework preset, install command, or build command is required.

The production files are:

- `dist/index.html` - portfolio site
- `dist/resume.pdf` - résumé opened by the site navigation and contact link

For local development, serve the `dist` directory with any static file server.
